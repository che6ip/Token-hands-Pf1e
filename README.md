# Руки на токене: PF1e

Дополнение к базовому модулю **«Руки на токене»** для системы **Pathfinder 1e** (`pf1`).

Модуль показывает на токенах персонажей и NPC, что у них в руках: оружие и щиты. Иконки рисует
базовый модуль, а этот модуль объясняет ему, какие предметы и сколько рук занимает.

## Что показывает

- Оружие в состоянии **«Экипировано»** (`system.equipped`).
- Щиты (`equipment` с подтипом `shield`), если они экипированы.
- Двуручное оружие (`system.held = "2h"`): активная иконка в правой руке, затемнённая копия в левой.
- Оружие в основной руке (`"1h"`) — справа.
- Оружие во второй руке (`"oh"`) — слева.
- Если основное оружие не задано, щит или оружие второй руки показывается слева.
- Пустая рука показывается **ладонью**, если вторая рука занята или для неё выбран предмет.
- **ПКМ по слоту** открывает меню: можно выбрать любую вещь из инвентаря для этой руки,
  вернуть автоматический выбор или принудительно сделать руку пустой.
- Предметы в меню сгруппированы по вкладкам инвентаря PF1e: оружие, броня/щиты, снаряжение,
  импланты, расходники и так далее. При большом количестве вещей появляется поиск по названию.
- Если в руках ничего нет, слоты не рисуются.

> **Важно:** оружие должно быть именно **Equipped / Экипировано**, а не просто
> **Carried / Несётся**. Предметы в инвентаре без галочки «Экипировано» модуль не считает
> находящимися в руках.

## Как это выглядит в игре

- Иконки появляются у нижних углов токена.
- **ЛКМ по иконке** открывает карточку предмета.
- Размер иконок, подъём над HP-баром и видимость рук настраиваются в базовом модуле.

## Требования

- Foundry VTT **13** (проверено на 13.351).
- Система **Pathfinder 1e** (`pf1`) версии **11.11+**.
- Базовый модуль **«Руки на токене»** (`token-hands`) версии **1.13.0+**.

## Установка

1. Установите и включите базовый модуль **token-hands**.
2. Установите этот модуль одним из способов:
   - в Foundry VTT откройте **Setup → Add-on Modules → Install Module** и вставьте ссылку на манифест:

     ```
     https://github.com/che6ip/Token-hands-Pf1e/releases/latest/download/module.json
     ```

   - или скопируйте папку `token-hands-pf1e` в `Data/modules/token-hands-pf1e`.
3. Включите модуль в настройках мира (**Manage Modules**).
4. Обновите сцену клавишей **F5**.

## Использование

1. Откройте лист персонажа или NPC.
2. Экипируйте оружие или щит.
3. Для двуручного оружия выберите хват **«Двуручное»** (`2h`), для оружия во второй руке — **«Вторая рука»** (`oh`).
4. Посмотрите на токен: иконки появятся автоматически.
5. Кликните по иконке, чтобы открыть карточку предмета.
6. **ПКМ по слоту** — выбрать предмет из инвентаря для этой руки. Выбор сохраняется в флагах
   токена и применяется только к нему; пункт **«Авто»** возвращает автоматический выбор,
   **«Пустая рука»** принудительно показывает ладонь.

## Настройки

Собственных настроек у модуля нет. Размер слотов, подъём над HP-баром, видимость и раскладка
настраиваются в базовом модуле **«Руки на токене»**.

## Совместимость

- Foundry VTT **13**.
- Pathfinder 1e (`pf1`) **11.11+**.
- Требуется `token-hands` 1.13.0 или новее.
- Репозиторий модуля: [che6ip/Token-hands-Pf1e](https://github.com/che6ip/Token-hands-Pf1e).
- Другие предметные модули (D&D 5e, Pathfinder 2e, Cyberpunk RED) можно включать одновременно:
  каждый провайдер берёт только актёров своей системы.
